# sentinel-learning-lab

> 本仓库是 **alibaba/Sentinel** 的学习整理派生仓库，原项目采用 **Apache-2.0** 许可证。
> 仅做目录梳理、中文说明与学习路径补充；源码逻辑保持不变，原作者版权与 LICENSE 一并保留。

## 原项目
- 上游：https://github.com/alibaba/Sentinel
- 分支：1.8　许可证：Apache-2.0

## 本仓库做了什么
1. 清理 CI/社区元文件（.github、devbox 等），保留 LICENSE 与版权声明。
2. 用中文重写说明文档，并补充学习路径。
3. 按模块拆分提交，提交信息详细、可对照目录学习。

## 目录结构（共 10 个顶层模块）
- `doc`
- `sentinel-adapter`
- `sentinel-benchmark`
- `sentinel-cluster`
- `sentinel-core`
- `sentinel-dashboard`
- `sentinel-demo`
- `sentinel-extension`
- `sentinel-logging`
- `sentinel-transport`

## 学习路径建议
1. 先读 `docs/learning-path.md` 了解整体脉络。
2. 按上方模块顺序逐个深入，优先核心模块。
3. 结合原项目 `README.en.md`（已保留）对照官方用法。
